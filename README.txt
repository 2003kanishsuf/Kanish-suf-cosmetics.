# Kanish Suf Business Book

## Included features
- Numbered receipts (KSC-0001 onward), customer and payment details
- Multiple items per receipt, discounts, partial payments and balances
- Print or save receipts as PDF; share a receipt summary
- Customer book and purchase totals
- Product stock register, low-stock alerts and sale stock deductions
- Expense register
- Date-filtered sales, collections, balances, expenses and estimated gross profit
- CSV sales export and full JSON backup/restore
- Offline-ready installable PWA package

## Important storage note
Records are stored locally in the browser on the device. They do not automatically sync to another phone. Use **Backup & Settings → Download full backup** regularly and store the JSON file in Google Drive or another safe place.

## Install on Android
For the full installable/offline app experience, upload the files in this folder to a secure HTTPS host (for example, your GitHub Pages website). Open the hosted `index.html` in Chrome, then use Chrome menu → Install app / Add to Home screen. Open the installed app once while online; it can then load offline.

You can also open `index.html` directly to use the app in a browser, but browser restrictions may prevent PWA installation/offline caching when opened as a local file.

## Restore
Open the app on the phone → Backup & Settings → Restore from backup → select your `.json` backup file.
